## 使用影响与后续建议

只读 Git 现在显示未经外部过滤器处理的工作树内容；Git LFS 等仓库的预览可能与过滤后的暂存结果不同。选定普通子目录时不会显示父仓库状态，需将 workspace 指向仓库根目录。Web 服务升级后需要重启并重新登录。

命令输出目前仍先由 `subprocess.run(capture_output=True)` 收集，再按界面/模型输出上限截断；大仓库或大量输出的质量检查仍有内存峰值风险。后续可单独实现带字节上限的流式进程采集，并保留完整审批摘要与进程取消语义。默认关闭的 OS 沙箱、宿主质量检查执行项目代码，以及没有独立子任务前端面板的产品边界保持现状。
